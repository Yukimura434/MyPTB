# User manual

## Administrator

Use Home to connect the camera and set photo count/countdown. Frames imports PNG layouts and detects transparent photo slots. Presets manages processing profiles. Printers detects Windows printers and saves the active profile. Diagnostics reports device, queue, disk and memory health.

## Customer

Tap Start, follow the countdown and Smile prompts, then review the captures. Choose a pinned frame and tap Print. When upload is configured, scan the QR code to download the final photo. Done clears temporary session captures and returns to Start.

If a device disconnects, wait for automatic recovery. Friendly retry actions remain available when recovery cannot finish.
